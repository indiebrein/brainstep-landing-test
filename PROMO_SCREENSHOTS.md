# Подготовка промо-скриншотов BrainStep

Эта инструкция фиксирует стиль промо-изображений для сайта и RuStore.
Исходные скриншоты приложения не изменять: итоговые композиции сохраняются
отдельно в `assets/promo`.

## Где находятся файлы

- исходные скриншоты версии: `C:\project\screen\<версия>`;
- готовые промо-изображения: `C:\project\site\assets\promo`;
- генератор для версии 1.0.3: `tools/generate_promo_1_0_3.py`;
- эталон геометрии телефона: один из уже утверждённых слайдов в
  `assets/promo`, например `05_find_pair.png`.

Имена файлов начинаются с двухзначного номера, определяющего порядок в
карусели: `01_...png`, `02_...png` и так далее.

## Обязательные параметры

- холст: **1080 × 1920 px**;
- разрешение: **144 DPI**;
- формат: PNG;
- основной шрифт: `C:\Windows\Fonts\arial.ttf`;
- жирный шрифт: `C:\Windows\Fonts\arialbd.ttf`;
- заголовок: Arial Bold, 74 px;
- служебная строка сверху: Arial Bold, 25 px;
- подзаголовок: Arial Regular, 30 px.

Для двухстрочного заголовка строки рисуются отдельно. В текущем шаблоне их
верхние координаты — **132 px** и **230 px**. Нельзя использовать случайный
межстрочный интервал многострочного текста: он визуально отличается от
утверждённых слайдов.

## Главное правило шаблона телефона

Не рисовать силуэт телефона, статус-бар, батарею, индикаторы сети и скругления
заново. Нужно открыть утверждённый промо-слайд и сохранить его телефонный
шаблон без изменений. Новый скриншот приложения накладывается только на
область экрана.

Для `09_number_search.png` используются параметры:

- исходный шаблон: `05_find_pair.png`;
- содержимое исходного скриншота начинается после `y = 140`;
- ширина вставляемого содержимого: `732 px`;
- позиция вставки: `x = 174`, `y = 627`.

Эти значения относятся к текущему шаблону. При выборе другого эталонного
слайда сначала нужно измерить его область экрана.

## Замена текста и фона

Старый текст нельзя удалять закрашиванием или интерполяцией широких
горизонтальных полос. Такой способ растягивает и размазывает фоновые круги.

Генератор должен:

1. выделить только тёмные пиксели старых букв;
2. немного расширить маску для сглаженных краёв шрифта;
3. восстановить фон только внутри маски;
4. нарисовать новый текст поверх восстановленного фона.

В `generate_promo_1_0_3.py` это делает функция `erase_template_text()`.

## Запуск генератора

Перед запуском закройте итоговый PNG в редакторе и отключите панель
предпросмотра Проводника: Windows может заблокировать перезапись файла.

Чтобы пересобрать только слайд «Поиск числа», не затрагивая остальные:

```powershell
cd C:\project\site
python -c "import tools.generate_promo_1_0_3 as m; m.create_number_search_slide()"
```

Если `python` отсутствует в `PATH`, используется Python из среды Codex:

```powershell
& 'C:\Users\shpar\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' `
  -c "import tools.generate_promo_1_0_3 as m; m.create_number_search_slide()"
```

Запуск всего файла также обновляет финальный слайд с логотипом, поэтому его
следует использовать только когда нужно пересобрать оба изображения.

## Проверка перед публикацией

Проверить изображение в масштабе 100% и рядом с эталонным слайдом:

- силуэт, ширина и положение телефона совпадают;
- отсутствуют случайные чёрные штрихи у верхних углов;
- вырез камеры, статус-бар, батарея и индикаторы совпадают с эталоном;
- шрифты, размер и насыщенность заголовков одинаковы;
- расстояние между строками заголовка одинаковое;
- фоновые окружности имеют ровные границы и не размазаны;
- игровой интерфейс не растянут и не обрезан;
- итоговый файл имеет размер 1080 × 1920 px и 144 DPI;
- `index.html` содержит только актуальные изображения в правильном порядке.

После визуальной проверки выполнить `git diff --check` и создать отдельный
коммит только с готовыми промо-файлами, генератором и этой документацией.
