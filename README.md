# BrainStep landing page

Статический лендинг BrainStep для публикации через GitHub Pages.

Текущая папка предназначена для тестовой публикации версии 1.0.4 по адресу
`https://indiebrein.github.io/brainstep-landing-test/`. В разметке установлен
`noindex`, поэтому тестовая копия не должна попадать в поисковую выдачу.

## Публикация

Файлы должны находиться в корне репозитория `brainstep-landing-test`.
После загрузки откройте **Settings → Pages**, выберите публикацию из ветки
`main` и корневой папки `/ (root)`.

Сайт не использует сервер, аналитику, cookie или внешние библиотеки.
Шрифты Manrope и Unbounded хранятся локально в `assets/fonts`, поэтому
страница не отправляет запросы в Google Fonts.

## Изображения

Разметка отдаёт WebP через `<picture>`, а исходные PNG остаются запасным
вариантом. Варианты по ширине, иконки и обложку для соцсетей собирает
скрипт — запускать после замены любого скриншота:

```
python tools/build_assets.py
```

Он создаёт рядом с исходниками `*-320.webp` и `*-640.webp` для галереи,
`*-360.webp` и `*-720.webp` для скриншотов в рамке телефона, уменьшенные
иконки и `assets/social-cover.png` (1200×630) для `og:image`.
Исходные PNG скрипт не изменяет и не удаляет.
